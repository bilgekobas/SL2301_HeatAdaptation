## Repository-level notes

- Manuscript terminology uses **AC**, whereas several processed files and scripts use **CC** for the continuously cooled / air-conditioned arm. These should be treated as equivalent unless renamed globally.
- The released datasets are processed and analysis-ready, not raw device exports.
- Raw physiological recordings and potentially identifiable source exports are not included in the public repository.
- Before the public release, check `hrv.csv` column `file`; it currently contains original local file paths. These should be converted to basenames or removed.
- Before the public release, check whether `cbt.csv` column `pillid` should be retained, hashed, or removed.
- This dictionary should be updated whenever new datasets, columns, or derived outcomes are added.
